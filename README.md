# Project Water

Statische leswebsite voor leerlingen van ongeveer 14–16 jaar. Leerlingen verzamelen waterstalen, meten pH met een sensor en Arduino en verwerken de klassendata met Python om hun hypothese te testen.

De landing page staat in `index.html`. De website gebruikt `style.css`, de map `media/` en het onderzoeksplatform in `platform.html`. De kaart met voorbeeldlocaties in Gent gebruikt Leaflet en OpenStreetMap.

## Belangrijke bestanden

- Landing page: `index.html`
- Onderzoeksplatform: `platform.html`
- Stijlen: `style.css`
- Media: `media/`
- Licentie: `LICENSE.md`
